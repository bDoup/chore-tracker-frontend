# Chore Tracker — Static App Skeleton

This repository contains a minimal static app scaffold intended for deployment via GitHub Pages. It includes a landing page and placeholder assets.

Quick start

- Customize the CSS (for example, add a Bootstrap link in `index.html` head).
- Push to your repository and enable GitHub Pages in the repository Settings → Pages → Source: `main` branch `/ (root)` or use the `gh-pages` branch.

Files added

- `index.html` — landing page
- `assets/css/styles.css` — starter styles
- `assets/js/main.js` — starter JS
- `.nojekyll` — prevents GitHub Pages from ignoring files starting with `_`
